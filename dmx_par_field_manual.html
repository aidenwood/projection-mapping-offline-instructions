Stage Technician's Field Manual

DMX Par Cans driven by Resolume Arena

Two RGB LED pars flanking a projection, sampling colour from the live composition to extend visuals onto the trees behind the stage. Hardware, network, software, and what to do when none of it works.

Section 01

Overview & gear list

What this manual gets you to, and the kit you need on the bench before you start.

You're building a setup where two RGB DMX par cans, positioned either side of a projection screen, automatically take on colours sampled from the edges of the video that Resolume is sending to the projector. The result is that coloured light spills onto the trees and surroundings behind the stage in a way that extends the projected image — making the screen feel less like a window and more like a centre of mass for a wider lit environment.

You'll need all of the following on hand:

Hardware

  • A computer running Resolume Arena (not Avenue — Avenue does not output DMX).
  • Two RGB LED par cans with DMX in/out (3-pin or 5-pin XLR-style sockets).
  • An Ethernet-to-DMX node (also called an Art-Net node or sACN node).
  • Power cables for the pars and the node.
  • Two DMX cables: one from the node to par 1, one from par 1 to par 2. Use proper 110-ohm DMX cable, not standard mic cable, for runs over a few metres. For short backstage hops, mic cable usually works but can introduce intermittent flicker on longer chains.
  • One 120-ohm DMX terminator (a male XLR plug with a resistor inside) for the end of the chain.
  • An Ethernet cable from the computer (or your router/switch) to the DMX node.

Information you need before you start

  • The DMX channel mode of your par cans (3-channel, 4-channel, 7-channel, etc.) and what each channel does. Check the manual or the fixture's onboard menu.
  • The IP address the node uses by default. Most nodes are either 2.x.x.x (Art-Net default) or 192.168.x.x. There's usually a sticker on it or a config tool from the manufacturer.
  • Whether your node speaks Art-Net, sACN (E1.31), or both. Art-Net is the most common for small setups.
Why Arena and not Avenue

Resolume sells two versions: Avenue (cheaper, no DMX output) and Arena (with DMX out, called Lumiverse, plus more advanced output mapping). If you open your software and there is no DMX or Lumiverse option anywhere in the menus, you have Avenue. There's no way to add DMX to Avenue short of upgrading the licence, or routing video out to a separate tool like MadMapper.

Section 02

Core concepts you should understand first

Five minutes of theory here will save you an hour of debugging later.

DMX-512

DMX-512 is a one-way serial protocol invented for stage lighting. A single DMX line is called a universe and carries 512 channels, each holding a value from 0 to 255. Every fixture on the line listens to a contiguous block of channels starting at its start address. So a 3-channel RGB par set to start at 1 listens to channels 1, 2, 3. Another 3-channel par on the same line set to start at 4 listens to channels 4, 5, 6. Two fixtures can share a start address — they'll just behave identically.

Art-Net & sACN

Art-Net and sACN are protocols that carry DMX universes over Ethernet. Your computer sends DMX data to the node over the network; the node converts it to a real DMX signal on the XLR cable. From the fixtures' perspective, it's just DMX — they don't know or care that it came over Ethernet first. Art-Net universes are sometimes numbered from 0 (Art-Net's native scheme) and sometimes from 1 (the way most lighting consoles display them). This off-by-one is the single most common source of "why aren't my lights responding" pain. We'll come back to this.

Lumiverse (Resolume's DMX feature)

Lumiverse is Resolume Arena's built-in DMX output system. It lets you place virtual fixtures on a 2D layout that corresponds to your composition. Each fixture has a pickup point — a small region on the composition canvas. Whatever colour the video shows at that point gets sent out as the fixture's RGB values. Drag the pickup, the sampled region changes. Make it bigger, it averages over a larger area.

The full chain in one sentence

Resolume reads pixels under each fixture's pickup → packs them into a DMX universe → sends that universe over Ethernet as Art-Net → your node receives it and outputs real DMX on its XLR port → DMX cable carries the signal to par 1, then daisy-chains to par 2 → each par reads its own channels from the stream and sets its LEDs accordingly.

Section 03

Network setup

Getting your computer and the DMX node onto the same network so they can actually talk.

The computer and the node need to be on the same subnet, with IP addresses that match in the first three octets but differ in the last. There are a few topologies that work:

Option A: Direct cable (recommended for live use)

Plug an Ethernet cable directly from the computer's Ethernet port to the node. No router involved. This is the most reliable option for a show — no Wi-Fi dropouts, no router rebooting itself mid-set, no other network traffic competing for bandwidth.

Because there's no router doing DHCP, you'll need to set a static IP on the computer's Ethernet interface manually. Pick something in the same range as the node's default IP.

Option B: Computer and node both on a router/switch

Works fine if you have a router handing out DHCP addresses to both. Just be aware: if your computer is on Wi-Fi and the node is plugged in by Ethernet, both connections need to be on the same subnet, and the computer needs to be told which interface to send Art-Net out on. (See Resolume preferences below.)

  1. Look up the node's default IP. Common defaults: Enttec ODE Mk2 ships at 10.0.0.1; many generic Chinese Art-Net nodes ship at 2.0.0.1 with subnet 255.0.0.0; some configurable nodes ship in DHCP mode and will only get an IP if connected to a router. Check the sticker on your unit, or the included manual.

  2. Set the computer's Ethernet adapter to a matching static IP. If the node is 2.0.0.1, set the computer to 2.0.0.10 with subnet 255.0.0.0. If the node is 192.168.1.50, set the computer to 192.168.1.10 with subnet 255.255.255.0. Leave the gateway field blank or set it to the node's IP — it doesn't matter for Art-Net.

    On macOS: System Settings → Network → Ethernet → Details → TCP/IP → Configure IPv4: Manually.

    On Windows: Control Panel → Network → Change adapter settings → right-click your Ethernet adapter → Properties → IPv4 → Properties → Use the following IP address.

  3. Test the connection with a ping. Open a terminal or command prompt and run ping 2.0.0.1 (or whatever your node's IP is). You should see replies. If you see "Request timed out" or "Destination host unreachable", the network is not configured correctly — fix this before doing anything else. There is no point opening Resolume until the ping works.

  4. Run the node's discovery/config tool if it has one. Many nodes ship with a small utility (Enttec NMU, Madrix node config, generic Art-Net Discovery tools) that scans the network and shows any nodes found. If your tool finds the node, the network is happy. If it doesn't, you have a network problem, not a Resolume problem.

Disable Wi-Fi during shows

If your computer is on Wi-Fi and Ethernet simultaneously, the OS may decide to send Art-Net out of the wrong interface, especially if both networks share IP ranges. Turn Wi-Fi off during shows, or explicitly tell Resolume which network interface to use (see Section 06).

Section 04

DMX wiring

The physical chain from node to pars to terminator.

Physical layout — DMX chain
   [Computer] ─── Ethernet ───→ [DMX Node]
                                     │
                                     │ DMX cable (XLR)
                                     ↓
                              ┌──────────────┐
                              │  Par Can 1   │  Address: 001
                              │   DMX IN     │  Mode: 3-channel RGB
                              │   DMX OUT  ──┼──┐
                              └──────────────┘  │
                                                │ DMX cable (XLR)
                                                ↓
                              ┌──────────────┐
                              │  Par Can 2   │  Address: 004
                              │   DMX IN     │  Mode: 3-channel RGB
                              │   DMX OUT  ──┼──┐
                              └──────────────┘  │
                                                ↓
                                          [Terminator]
                                          (120-ohm plug)

  1. Power off the pars before plugging anything in. Not strictly required but good practice — a power-on inrush can confuse the addressing menu on cheaper fixtures.

  2. Connect Ethernet to the node, then power the node. Wait 10–20 seconds for it to boot fully. Most nodes have status LEDs — typically a "link" LED that goes solid when Ethernet is connected, and a "DMX" LED that flashes when DMX data is being sent out. Right now only the link LED should be on.

  3. Run a DMX cable from the node's DMX output to par 1's DMX IN. Note the direction matters: DMX is one-way, and the cable connects to the IN of the next device in the chain. If your par has both an IN and OUT (most do), you'll be using the IN socket here.

  4. Run a second DMX cable from par 1's DMX OUT to par 2's DMX IN. This is the daisy chain. The DMX signal passes through par 1 (it's still listening to its own channels) and continues on to par 2.

  5. Plug the terminator into par 2's DMX OUT. The terminator is a 120-ohm resistor inside an XLR housing — it absorbs the signal at the end of the chain so it doesn't reflect back down the cable and cause data corruption. For a two-fixture chain over short distances you can usually get away without one, but if you ever see random flickering, the missing terminator is the first thing to suspect.

  6. Power on the pars. They should come up to their default state (often blackout, sometimes a startup colour cycle). Don't be alarmed if they flash briefly.

3-pin vs 5-pin XLR

DMX is officially specified as 5-pin XLR, but the entry-level and mid-tier fixture industry standardised on 3-pin XLR (using only 3 of the 5 pins). Your pars and node are almost certainly 3-pin. If you have one 3-pin and one 5-pin device, you'll need an adapter — don't try to use a standard mic cable as a substitute for a long run.

Section 05

Addressing the par cans

Telling each par which slice of the DMX universe it should listen to.

Each par needs two settings on its onboard menu: a mode (how many channels it uses) and a start address (the first channel it listens to). The menu is usually a small 3- or 4-digit LED display with a few buttons labelled MENU, UP, DOWN, ENTER, or similar.

Find the channel mode first

RGB pars come in many modes. Common ones:

ModeChannels usedWhat they do
3CHR, G, BPure colour mixing. Simplest. Use this if available.
4CHR, G, B, DimmerAdds a master dimmer channel. Set dimmer to 255 (full) to see colour.
5CHR, G, B, Dimmer, StrobeDimmer + strobe. Strobe usually 0 = no strobe.
7CHR, G, B, Dimmer, Strobe, Macro, SpeedAdds factory colour macros and macro speed. Set macro channel to 0 to disable.
8CH+variesOften includes RGBW (white channel) or RGBA (amber) — check fixture manual.
Pick the simplest mode that works

Use 3-channel mode if it's available. Fewer channels = fewer things to misconfigure. If your par only offers 7-channel mode, that's fine — just remember to set the extra channels (dimmer to full, strobe to 0, macro to 0) in Resolume's fixture profile.

Calculate addresses

Each par's start address is the channel number after the previous par's last channel.

SetupPar 1 addressPar 2 address
3-channel mode001004
4-channel mode001005
5-channel mode001006
7-channel mode001008
8-channel mode001009

  1. On par 1, navigate to the channel mode setting. The label varies: "MODE", "PROFILE", "CHANNELS", "CH", "P". Set it to your chosen mode (typically 3CH).

  2. Set par 1's start address to 001. The display might show A001, d001, 001, or CH 1. Confirm/enter to save.

  3. On par 2, set the same channel mode. Both pars must be in the same mode — if one is 3CH and the other is 7CH, your channel maths will be wrong and they'll respond strangely.

  4. Set par 2's start address to match the next free channel. For 3CH mode, that's 004.

  5. Power-cycle the pars (some fixtures only apply settings on reboot). Not all need this, but it doesn't hurt.

Section 06

Resolume Arena configuration

Telling Resolume where to send Art-Net, what fixtures live on the universe, and how to test them.

Menus and naming have shifted slightly between Resolume versions (7.x has DMX under Output, newer versions consolidate it under Lumiverse). The concepts below apply regardless — find the equivalent panel in your version.

  1. Open the DMX / Lumiverse panel. In Resolume 7: Output → Advanced → DMX tab. In newer versions there's usually a dedicated Lumiverse window accessible from the menu bar or by toggling a panel.

  2. Set the network interface. Somewhere in Resolume's preferences or the Lumiverse panel there's an "Adapter" or "Network Interface" setting. Set this explicitly to the Ethernet adapter connected to the node. If you leave it on "Auto" or "Default", Resolume may try to send Art-Net out of Wi-Fi and never reach the node.

  3. Add an output universe. Click "Add Universe" or "+". Choose your protocol: Art-Net for nearly all small setups. Set the universe number — start with 0. (We may need to change this to 1 if the node disagrees; see troubleshooting below.)

  4. Set the target IP. Two options here:

    Unicast: Enter the node's specific IP address. Resolume sends Art-Net only to that address. Cleanest for live use.

    Broadcast: Enter the broadcast address for your subnet (e.g. 2.255.255.255 for a 2.x.x.x network, or 255.255.255.255 for global broadcast). Resolume blasts Art-Net to every device on the network. Works but generates more network traffic.

    Try unicast first. If the node doesn't respond, fall back to broadcast.

  5. Open the fixture library / patch panel. This is where you add virtual fixtures that map to your physical pars.

  6. Add fixture 1: search for your par can model. Resolume ships with a library of common fixtures. If yours is listed, pick it. If not, choose a generic "RGB" fixture matching your channel count. If even that's not available, you can build a custom fixture profile — add it as a new fixture with channels labelled R, G, B (in the right order; some fixtures use G-R-B or B-G-R, check your manual).

  7. Set fixture 1's address to universe 0, address 001. The address must match what's set on the physical par. Double-check.

  8. Add fixture 2 the same way, with start address 004 (or whatever your second par's physical address is).

  9. Test fixture 1 with the manual colour picker. In the Lumiverse fixture view there's usually a way to override the fixture's colour with a colour picker or manual sliders. Set par 1 to bright red. The physical par 1 should immediately glow red. If it doesn't, stop and debug before continuing — see troubleshooting Section 09.

  10. Test red, green, and blue independently. If red triggers green, or blue triggers red, your channel order in the fixture profile is wrong. Swap the channel assignments in the fixture's custom profile until R→red, G→green, B→blue on the physical par.

  11. Repeat the manual test for fixture 2. Verify it lights up independently from fixture 1. If both pars respond to fixture 1's controls in Resolume, par 2 has the same start address as par 1 — go back and fix par 2's address.

  12. Remove any manual overrides so the fixtures take their colour from the composition rather than the override.

The universe 0 vs 1 trap

Art-Net internally numbers universes from 0. Many lighting consoles and node config screens display them starting from 1. If you set Resolume to universe 0 and the node's web interface shows universe 1, those are the same universe. If you set Resolume to universe 1 and the node also expects universe 1, you might actually be one off. If your test colour change in Resolume produces no light, swap Resolume's universe between 0 and 1 and try again before anything else.

Section 07

Positioning the pickups

Telling each virtual fixture which part of the composition canvas to sample its colour from.

In the Lumiverse fixture layout view there's a 2D representation of your composition canvas with the virtual fixtures shown as draggable points or boxes. Whatever colour appears at that point in the composition becomes the fixture's output colour, in real time.

Pickup placement — matching pars to projection edges
    Composition canvas (what Resolume outputs to projector)
    ┌─────────────────────────────────────────────────┐
    │ ◉                                             ◉ │
    │ │                                             │ │
    │ │           [ main video content ]            │ │
    │ │                                             │ │
    │ ◉                                             ◉ │
    └─────────────────────────────────────────────────┘
      ↑                                             ↑
      Fixture 1 pickup                Fixture 2 pickup
      (samples left-edge colour)      (samples right-edge colour)

    Physical layout:

    [Par 1]    [Projector beam / screen]    [Par 2]
       \\           |||||||||||||           /
        \\          |||||||||||||          /
         → trees   |||||||||||||   trees ←

  1. Open the fixture layout view. This is the 2D canvas where you can drag fixtures around. The background should show a thumbnail of your current composition output.

  2. Drag fixture 1 to the far left edge of the composition. How close to the edge depends on your content — a few percent in from the absolute edge usually averages over more meaningful colour. If your content has a hard letterbox at the edges (black bars), move the pickup further in so it doesn't just sample black.

  3. Drag fixture 2 to the far right edge, symmetric to fixture 1. The visual symmetry on stage will read better if the sample points are also symmetric.

  4. Adjust the pickup size. Each fixture has a "size" or "area" property (sometimes a slider, sometimes a draggable bounding box). A larger area means the fixture averages colours over more pixels — smoother, less flickery, but less responsive to small details. A smaller area is more punchy but can flicker on detailed content. Try a region that's roughly 5–10% of the canvas width.

  5. Play a test clip and watch the pars. Run something with strong colour movement (a clip that goes red, green, blue, white, black in sequence works well). The pars should track. If they don't, see troubleshooting.

  6. Walk to the actual stage position and look at how the colour lands on the trees. You may need to come back and adjust pickup positions if the par output feels disconnected from what's on the screen — for example, if a clip has dark edges but a colourful centre, you might want the pickups inset from the edges to grab the more interesting colour.

Master dimmer per fixture

Each Lumiverse fixture has its own master dimmer, separate from the colour. If your pars are coming on at full brightness and blowing out the trees, drop the master dimmer on each fixture to something like 60–70%. This is a more reliable way to limit brightness than relying on darker video content.

Section 08

Designing content for this setup

How to make your visuals work with the lights rather than against them.

Once everything is wired and patched, the next reality check is that not all content drives lights well. A few principles that will save you grief:

Saturated edges beat busy detail

If your composition has a complex centre but washed-out grey edges, the pars are going to look like cheap work lights. Edge colour matters more here than overall colour, because that's what the pickups are reading. When picking or making clips, glance at the left and right edges specifically — is there colour there?

White content makes white pars

And white RGB pars usually look ugly on foliage — slightly green-tinted, flickery, not at all like daylight or moonlight. If your content goes to white frequently, either pull the par master dimmer down on those clips, mask the pickup zones, or accept the look and design around it.

Build a dedicated DMX layer

This is the single biggest quality-of-life upgrade. Make a new layer in Resolume that's hidden from the projector output (mute it on the output transform, or composite it below others with opacity 0 on screen but still readable by Lumiverse — depending on how your version of Arena routes content, you may need to experiment). Put solid colour blocks or wide gradients on this layer, positioned at the left and right edges of the canvas. The pickups read from this layer, not your main visuals.

The advantage: you can pick the lighting colour completely independently from the projected image. Want red lights during a blue projection? Easy. Want lights to pulse on the beat while the projection holds steady? Just animate the DMX layer.

Avoid hard cuts unless you want hard cuts

If your composition has a hard cut from colour A to colour B, the pars will switch instantly too. Sometimes that's the look you want — explosive, punctuating. But if you want the par colour transitions to feel atmospheric, add a transition or fade between clips on the DMX layer specifically.

Be aware of projector latency

Most projectors introduce 1–3 frames of input lag. LED pars are essentially instant. So the par colour change will hit the audience's eye slightly before the projected change does. For most content this is unnoticeable. For tight cuts on music, you can introduce a delay effect on the DMX layer (or on the fixture output if your Lumiverse version supports it) to nudge things back in sync.

Section 09

Troubleshooting

Symptom → likely cause → fix. Click any heading to expand.

No lights respond to anything in Resolume

Most likely: Resolume is sending Art-Net to the wrong network interface, the wrong IP, or the wrong universe number.

Work through this in order:

  1. Ping the node from your computer. If ping fails, the network is broken — fix that first.
  2. In Resolume's preferences, explicitly select the Ethernet adapter as the Art-Net network interface. Don't leave it on Auto.
  3. Try switching the universe in Resolume between 0 and 1. The off-by-one between Art-Net's internal numbering and node config tools catches everyone.
  4. Try switching from unicast to broadcast (e.g. 2.255.255.255). If broadcast works and unicast doesn't, you have the node's IP wrong in Resolume's universe config.
  5. Check the node's DMX activity LED. If it's not flashing, Resolume isn't reaching the node at all — network problem. If it is flashing but the pars are dark, the node is receiving data but it's not getting to the pars — DMX cable, addressing, or fixture mode problem.
Par 1 works, par 2 doesn't

Most likely: The DMX cable between par 1 and par 2 is bad, plugged into the wrong sockets, or par 2's address is set wrong.

  1. Confirm the cable runs from par 1's DMX OUT to par 2's DMX IN. Reversed connections silently fail.
  2. Swap the cable for a known-good one. DMX cables die — especially the cheap ones, especially after being coiled and uncoiled a hundred times.
  3. Check par 2's address on its onboard display. If it shows 001 instead of 004, both fixtures will respond to fixture 1's data in Resolume — and fixture 2 in Resolume will be sending data to channels nothing is listening to.
  4. Swap the pars physically. If par 2 starts working in par 1's position, the problem is the cable or par 2's IN socket. If par 2 still doesn't work in par 1's position, par 2 itself is faulty.
Both pars light up but the colours are wrong

Most likely: The fixture profile in Resolume has the wrong channel order. Some pars use R-G-B, some G-R-B, some B-G-R.

  1. In Resolume, manually drive each colour to full one at a time and note what the physical par shows.
  2. If "red" in Resolume produces green on the par, your fixture profile has channels 1 and 2 swapped. Edit the profile to swap them.
  3. Some pars also have a separate "white" channel that needs to be set to 0 in your fixture profile — otherwise the fixture pumps white over your colour and everything looks washed out.
  4. Some have a "macro" channel that, if set to anything non-zero, overrides RGB with factory colour presets. Pin macro to 0 in the profile.
Both pars work but are very dim

Most likely: A master dimmer channel somewhere in the chain is not at full.

  1. Check the par's channel mode. If it's 4CH+ (anything with a dedicated dimmer channel), the fixture profile in Resolume needs to set the dimmer to 255. Most built-in profiles do this automatically, but custom profiles might not.
  2. Check the fixture's master dimmer in Lumiverse — it's a per-fixture slider that scales everything down.
  3. Check the composition layer's opacity — if the layer the pickup is reading is at 50% opacity, the colours read out at 50% too.
  4. Some pars have an onboard brightness limit in their menu (sometimes called "max output" or "DIM"). Check the par's menu — set it to 100%.
Pars flicker randomly

Most likely: Missing terminator, bad DMX cable, or network packet loss.

  1. Put a 120-ohm terminator on the last fixture's DMX OUT. The single most common cause of flicker on small chains.
  2. Swap the DMX cable between par 1 and par 2 for a known-good one.
  3. If you're on Wi-Fi, switch to wired Ethernet. Wi-Fi drops packets, and dropped Art-Net packets cause flicker.
  4. Check that no other software on your computer is also sending Art-Net (an old DMX program left running, a lighting console connected via Art-Net at the same time, etc.). Two Art-Net sources fighting on the same universe produces chaos.
  5. If you have other devices on the network generating heavy traffic (file transfers, video streaming, etc.), disconnect them. Art-Net is timing-sensitive.
Manual colour picker works but video content doesn't drive the pars

Most likely: The pickup point is over a black/empty area of the composition, or in a region that no layer occupies.

  1. Open the fixture layout view and check where the pickup actually is. Drag it onto a clearly coloured part of the composition.
  2. Make sure the composition canvas is showing content. If you've muted all layers or have the composition blacked out, the pickups read black.
  3. Some Lumiverse setups separate "screen" output from "Lumiverse" output — make sure the layers you want sampled aren't excluded from Lumiverse.
  4. Check that you removed any manual colour override on the fixture. An override persists until you clear it, and it'll block sampled colour.
Node's link LED is off / Ethernet not detected
  1. Try a different Ethernet cable. Cheap cables fail more often than you'd expect.
  2. If you're going through a switch, try direct cable instead.
  3. Check that the computer's Ethernet port is enabled (some laptops have it disabled by default in BIOS or in OS settings).
  4. If the node has a power LED that's off too — the node isn't powered. Check its power supply.
Both Wi-Fi and Ethernet active — confusing the network stack

Modern OSes try to be helpful by routing traffic out the "best" interface. For Art-Net you want explicit control.

  1. Easiest: disable Wi-Fi entirely during the show.
  2. In Resolume, explicitly bind Art-Net output to the Ethernet adapter (not Auto).
  3. On macOS, you can change the network service priority in System Settings → Network → Set Service Order — move Ethernet above Wi-Fi.
Pars respond but with noticeable lag behind the video

Usually a sign of either heavy CPU load on Resolume or a slow network path.

  1. Check Resolume's FPS — if it's struggling to render the composition, Lumiverse will lag too.
  2. Wired Ethernet is much lower latency than Wi-Fi.
  3. Some nodes have a buffer/smoothing setting in their config that adds delay. Check the node's web interface and turn smoothing down or off if present.

Section 11

Glossary

Quick reference for terms that come up throughout the manual.

Address (start address)
The first DMX channel a fixture listens to. A 3-channel fixture at address 4 listens to channels 4, 5, and 6.
Art-Net
The most common protocol for sending DMX over Ethernet. Created by Artistic Licence; royalty-free; supported by basically every node manufacturer.
Avenue
Resolume's lower-tier product. Cannot output DMX. If you have Avenue, this manual doesn't apply — you need Arena.
Broadcast
A network mode where packets are sent to every device on the subnet at once, rather than one specific IP. Used as a fallback when unicast doesn't work.
Channel mode
How a fixture interprets the channels it listens to. A 3-channel mode might use R, G, B. A 7-channel mode might use R, G, B, dimmer, strobe, macro, speed.
Daisy chain
Connecting multiple DMX fixtures in series: node → fixture 1 IN → fixture 1 OUT → fixture 2 IN → terminator. All fixtures share the same DMX signal.
DMX-512
The serial lighting protocol. One universe = 512 channels of 8-bit data, refreshed ~44 times per second.
Fixture profile
A definition file (or in-software entry) describing how a fixture's channels map to its functions. Different brands of "RGB par" can need different profiles even though they're functionally identical.
Lumiverse
Resolume Arena's built-in DMX output system, which samples colours from the composition and converts them into DMX output.
Node (DMX node / Art-Net node)
The hardware box that converts Ethernet Art-Net or sACN traffic into real DMX signals on XLR cables.
Pickup (pickup point)
A position on the composition canvas where a Lumiverse fixture reads its colour from. Draggable; can be resized to sample over a larger area.
sACN (E1.31)
An alternative protocol to Art-Net for carrying DMX over Ethernet. More modern, slightly more network-friendly. Supported by some nodes; usually interchangeable with Art-Net in practice.
Subnet
A range of IP addresses that share the same network. Devices on the same subnet can talk directly; devices on different subnets need a router. For Art-Net, computer and node must be on the same subnet.
Terminator
A 120-ohm resistor in an XLR-shaped plug, placed at the end of a DMX chain to absorb signal reflections.
Unicast
A network mode where packets are sent to one specific IP address. The cleanest way to send Art-Net to a known node.
Universe
A single DMX-512 channel group of 512 channels. One universe = one DMX line. Larger rigs use multiple universes; you only need one for two pars.
