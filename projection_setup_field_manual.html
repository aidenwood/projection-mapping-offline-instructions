Stage Technician's Field Manual · Volume I

Projection Mapping Rig — Whole Setup

Your entire show in one document: Windows main machine running Resolume Arena, a Mac running TouchDesigner bridged in over NDI, projection onto a mapped stage, DMX par cans, and how to run all of it without a single line of internet.

Section 01

Rig at a glance

A bird's-eye view of every box on the truck and what role it plays.

This is a multi-machine projection mapping rig. The Windows machine running Resolume Arena is the show brain — it owns the projector output, the DMX universe, and the master clock. Everything else is a feeder or a follower.

You have two primary content sources:

  • Resolume Arena (Windows) — main composition, clip playback, beat-synced effects, projection mapping via Advanced Output, DMX output via Lumiverse.
  • TouchDesigner (Mac) — generative content, real-time PBR materials over the stage map, particles, anything Resolume can't natively do. Bridges to Resolume over NDI.

Two output targets:

  • Projector — hard-edged onto a mapped surface (cyc, stage flats, a sculpture, whatever you've built for this gig).
  • DMX fixtures — par cans flanking the projection, plus any moving heads. Driven by Resolume Lumiverse out an Art-Net node.
Why the split

Resolume is unbeatable at clip launch, layer compositing, and reliable projection out. It is mediocre at generative 3D, PBR, and shader work. TouchDesigner is the opposite. Bridging them with NDI gives you both without trying to force either tool to do the other's job.

Section 03

Hardware inventory

Everything that needs to come out of the case before doors.

Compute

  • Windows machine — main, running Resolume Arena. Discrete GPU, two display outputs minimum (one for monitor, one for projector).
  • Mac — secondary, running TouchDesigner. Any model with a halfway decent GPU works for what we're doing.

Networking

  • Gigabit Ethernet switch — 5-port unmanaged is fine. Don't skimp; 100 Mbit will choke NDI at 1080p.
  • Three Cat6 cables: Windows ↔ switch, Mac ↔ switch, DMX node ↔ switch. Test each one before the show with a cable tester or by checking link lights.
  • No router. No internet. The switch is the entire network.

Display

  • Projector — whatever you're using. Know its native resolution and lumen rating. Bring a spare HDMI cable.
  • HDMI cable from Windows to projector. If it's a long run (over ~8m), use an active/fibre HDMI or you'll get sparkle and dropouts.
  • Operator monitor for Windows.

DMX / lighting

  • Art-Net node — Enttec ODE, generic Chinese unit, doesn't matter as long as you've tested it.
  • DMX cables, 120-ohm terminator, fixtures, power cables. Full chain detail is in the DMX Par Cans field manual.

Audio / control

  • Audio interface for BPM detection and audio-reactive FX.
  • MIDI controller (Akai APC, Novation Launchpad, Korg nanoKONTROL — whatever you've mapped to).
  • USB hub if you're running out of ports on the Windows machine.

Spares — non-negotiable

  • One spare HDMI, one spare Ethernet, one spare XLR/DMX, one spare USB cable per controller type.
  • Power board with switches per outlet. Gaffer tape. A torch. A multi-tool.
  • USB stick with installers for Resolume, TouchDesigner non-commercial, NDI Tools, and your Art-Net node config utility. Internet will not save you on the day.
Section 04

Show-day boot order

The order matters. Doing this out of sequence costs you 20 minutes of debugging.

  1. Power the switch first. Wait for all link lights to come up steady before plugging anything in. A switch that's still negotiating won't let Art-Net through cleanly.

  2. Plug Ethernet from both computers and the DMX node into the switch. Confirm link LED on each port. No link = bad cable or bad port. Swap before powering further.

  3. Power on the DMX node and fixtures. Fixtures will boot to their default state — par cans usually blackout, moving heads will home (calibrate their pan/tilt motors). Let the moving heads finish homing before you do anything else; they make horrible noises and you don't want to confuse "homing" with "broken."

  4. Power on the projector. It needs the longest warm-up time of anything in the rig. Lamp projectors need 60+ seconds, even laser ones want 30. Get it lit early.

  5. Power on the Windows machine. Confirm static IPs are set (see the network sections of the individual manuals). Disable Wi-Fi. Open Resolume Arena after the projector has reached its native resolution, otherwise Windows may decide your projector is 720p and Resolume will inherit that.

  6. Power on the Mac. Confirm static IP. Disable Wi-Fi. Open TouchDesigner and load your project. Don't start any NDI senders yet — Resolume needs to be receiving first if you want to verify the link.

  7. Open Resolume Arena. Load the show composition. Verify Advanced Output is targeting the right screen. Verify Lumiverse is sending to the correct Art-Net node IP.

  8. Start the NDI sender in TouchDesigner. In Resolume, add an NDI Source layer. The Mac's stream should show up in the source list within a few seconds. If it doesn't, see the NDI manual.

  9. Run a soft test of every layer. Trigger one clip per column. Fade DMX up and down. Tilt a moving head. Confirm projection mapping aligns with the surface. Now you're ready for doors.

Don't skip the soft test

It takes 90 seconds and catches the things that will otherwise blow up at 30 seconds before showtime. The single biggest cause of show-night panic is "it was working in soundcheck and now it isn't" — and almost every time it's a cable that got bumped during the changeover.

Section 05

Resolume — the main machine

Settings to lock in before the doors open.

Preferences worth checking

  • Preferences → Video → Renderer — set to your GPU explicitly, not "Auto." Auto can pick the integrated GPU on hybrid systems.
  • Preferences → Audio — set the audio interface as the input device so BPM detection works.
  • Preferences → DMX → Lumiverse — confirm Art-Net is enabled, the node's IP is reachable, universe number matches your fixture profile.
  • Preferences → MIDI — confirm your controller is enabled. Map clip launch buttons now, not during the show.
  • Preferences → OSC — turn on if you're sending OSC from TouchDesigner for parameter control. Default port 7000.

The Advanced Output window

This is where projection mapping lives. Output → Advanced. The left panel is your composition; the right panel is what gets sent to which physical screen. Drag a slice from the composition onto a screen, then warp the corners to match your surface.

Lock the Advanced Output file once you've mapped. Save it. Then save it again under a different name as a backup, on a separate drive. If you lose your mapping the night of the show, you are sunk — there is no quick way to rebuild it.

Slices vs screens

A screen in Resolume is a physical output (an HDMI port). A slice is a quad with input UVs and output corners — you can have many slices feeding one screen. For a single-projector setup, you usually want one screen and one or more slices per mapped surface.

Section 06

Projection mapping basics

A working method for getting pixels to line up with physical things.

  1. Set the projector to its native resolution. Anything else introduces internal scaling that softens the image and shifts the keystone subtly. Look up the spec; force the Windows display to match.

  2. Set the composition resolution to match the projector. Composition → Settings. If your projector is 1920×1200, set the comp to 1920×1200, not 1920×1080.

  3. Position the projector physically. Centred, lens shift used before you touch optical zoom, and ideally orthogonal to the main surface to minimise keystone correction. Every degree of off-axis softens detail at the edges.

  4. Open Advanced Output and add slices for each mapped surface. Start with a grid test pattern as the composition source — easiest reference for getting straight lines straight.

  5. Drag slice corners to align with your surface. Use the keyboard arrows for pixel-perfect nudges. The grid lines should land exactly on the edges of the physical object you're mapping onto.

  6. Add edge softening only at the very end, after geometry is locked. Soft edges on a misaligned slice will mask the misalignment until you turn them off and see the gap.

Mark the projector position

Once your map is dialled in, tape the projector's feet to the surface it's sitting on. Mark the lens position with a paint pen if you can. If the projector gets bumped during a changeover, you need to be able to return it to within a millimetre. A bumped projector with no reference marks is a 30-minute remap.

Section 07

Audio & timecode

How the show stays in sync with whatever's making noise.

Audio in

The simplest workflow: a feed from the FOH desk into your audio interface, Resolume listens to that input, tap-tempos lock to it, audio-reactive effects modulate from the levels. You want a line-level signal — ask the FOH engineer for a post-fader monitor send.

BPM & clock

Resolume can detect BPM from audio, but it's unreliable on anything other than a four-on-the-floor kick. For genres where BPM detection struggles (live bands, anything with rubato), tap-tempo manually with a MIDI button or a keyboard key. Don't try to "fix" the BPM detector mid-show — just tap it.

Timecode

If the music is on click and you've got a timecode source (LTC, MTC), you can drive Resolume's transport from it. Preferences → MIDI → MTC In. Lock comp playback to MTC and you'll never have to launch a clip manually for that segment of the show. This is overkill for most gigs but lifesaving for tightly scripted ones.

Section 08

DMX & lighting hooks

Coloured pars taking their colour from the projection.

Detail of how to address fixtures and configure Lumiverse lives in the separate DMX Par Cans field manual. What lives here is the integration story: the rig is set up so the pars sample colour from the edges of the composition and extend the projection's palette out into the room.

If you want pars highlighting a 3D feature on the mapped surface — say, picking out the silhouette of a sculpture with a moving spot — that's the territory of the PBR & moving lights manual. The short version: place a virtual fixture inside Lumiverse whose pickup point is on the part of the composition where the PBR overlay is rendered, and the par will track its colour automatically.

Section 09

Operating fully offline

The internet is not coming to save you. Here's how to ensure you don't need it.

Before you leave the studio

  • Open Resolume Arena while online and let it check its licence. The licence check caches for a long time. If you've launched it within the last week or two on the same machine, it will run offline at the venue.
  • Same for TouchDesigner — open it, sign in to the non-commercial licence (or your paid one), let it phone home once.
  • Pre-cache all your media. Resolume's preview generation is slow on first load. Open the composition, scroll through every column, let every clip generate its thumbnail and audio cache.
  • Disable auto-update on Windows and macOS. An update prompt mid-show is a nightmare scenario.
  • Turn off any cloud sync (Dropbox, iCloud, OneDrive) that touches the show folder. It will choke when offline and slow file I/O.

At the venue

  • Disable Wi-Fi on both machines. This is a hard rule — see the network section of the other manuals for why.
  • Don't bring up any browser. If you accidentally open Chrome and it tries to sync 500 tabs over a dead connection, you'll hammer the network.
  • Your "network" is just the switch. Static IPs only.
Licence catch

If a software licence happens to time out the day of the show and you have no internet, you are dead in the water. Mitigate by: (1) launching every piece of software at home the morning of the show, (2) packing a phone hotspot as a last-ditch emergency tether, (3) knowing the offline activation procedure for your Resolume licence in advance.

Section 10

Troubleshooting

The most common symptoms and how to chase them down.

Projector shows the desktop, not Resolume's output

Resolume isn't routing to the right screen. Output → Advanced → check that a screen exists for the projector's resolution and is set to Fullscreen. Common cause: Windows reassigned display IDs after a cable reconnect. Solution: re-pick the screen in Advanced Output, or in Output → Screen → Display.

NDI source from the Mac isn't showing up on Windows

See the NDI field manual for the full chase. First two checks: (1) both machines on the same subnet — ping one from the other. (2) Wi-Fi disabled on the Mac. NDI defaults to whichever interface has the highest metric, and Wi-Fi often wins by default.

Resolume is dropping frames during the show

Open the FPS meter (top right of the composition view). If it's below your composition framerate consistently, you're GPU- or disk-bound. Quick wins: lower preview resolution in Preferences → Video, close other GPU-heavy apps, make sure clips are on an SSD not a spinning disk, drop the NDI source's resolution if it's running 4K when 1080p would do.

Audio analysis isn't responding to music

Preferences → Audio — confirm the right input device is selected and the level meter is moving. If the meter is flat, you have no signal — bad cable or wrong source. If the meter is moving but BPM isn't detecting, tap-tempo manually and keep going.

DMX pars aren't responding at all

Three-layer check: (1) is Lumiverse sending? Open the Lumiverse view in Resolume, drag a fader manually, watch for the node's DMX-out LED to blink. (2) Is the node receiving? Use the node's discovery utility to verify it sees Art-Net packets. (3) Is the fixture chain intact? Try plugging the node's DMX direct into par 2, bypassing par 1, to isolate a bad cable.

Everything looks dim or washed out on the projector

Common causes: (1) Windows is in HDR mode and Resolume is outputting SDR — turn HDR off. (2) Projector is in eco mode, raise lamp/laser power. (3) Composition is rendering in a low colour space — check Composition → Settings → Color. (4) Ambient stage light is killing your contrast — talk to LD about reducing front wash on the surface you're mapping onto.

The whole rig was working, now it's not, and you didn't change anything

You changed something — you just didn't notice. The most common culprit during a gig: someone walked past and pulled a cable a few millimetres out of its socket. Walk the entire signal chain physically. Re-seat every connector. 90% of "I didn't change anything" problems are a loose connector. The other 10% are Windows quietly auto-updating a driver.

Section 11

Show-day checklist

Tick each one. Trust nothing.

  • Both machines launched while still on home internet, licences refreshed.
  • All media pre-cached — every clip thumbnail visible without lag.
  • USB stick with installers and backup show file in the kit bag.
  • Auto-update disabled on Windows and macOS.
  • Cloud sync paused or signed out on both machines.
  • Wi-Fi disabled on both machines.
  • Static IPs configured and pingable across the switch.
  • Switch powered, all link lights solid.
  • DMX node discoverable; fixtures addressed and homed.
  • Projector at native resolution; Windows display matches.
  • Advanced Output mapping loaded; geometry verified against grid pattern.
  • NDI source from the Mac visible in Resolume's source list.
  • Audio interface level meter moving when music plays.
  • MIDI controller mapped; soft-test every clip column.
  • DMX pars respond to a manual Lumiverse fader.
  • Backup show file saved to a second drive.
  • Projector position taped, lens position marked.
  • Spare cables (HDMI, Ethernet, XLR, USB) within arm's reach.
  • Torch, multi-tool, gaffer tape on the desk.
  • Phone hotspot configured but turned off — emergency only.
Section 12

Glossary

Quick definitions for the rest of the manual set.

Advanced Output
Resolume's projection mapping interface. Where you slice the composition into quads and warp them onto physical surfaces.
Art-Net
A protocol that carries DMX universes over Ethernet. The standard way to feed an Art-Net node from a computer.
Composition
Resolume's top-level project: layers, columns of clips, effects, and the master output. The thing you save as .avc.
Lumiverse
Resolume Arena's built-in DMX output feature. Lets you place virtual fixtures over the composition and pick up colour from them.
NDI
Network Device Interface. NewTek's protocol for sending video over Ethernet. Cross-platform, low-latency, gigabit-friendly.
PBR
Physically Based Rendering. A material model using albedo, normal, roughness, and metallic maps to make 3D surfaces look photoreal under lighting.
Slice
In Resolume Advanced Output, a quad with input UV coordinates and freely-warped output corners. The atomic unit of projection mapping.
Syphon
Mac-only protocol for passing video frames between apps on the same machine via shared GPU memory. The Mac equivalent of Windows' Spout.
TouchDesigner
Node-based real-time visual programming environment, particularly strong at generative content, shaders, and 3D scenes. Runs cross-platform.
